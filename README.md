# Городская поликлиника №8

> Веб-приложение для записи на приём к врачу с возможностью переключения темы.

---

## 📌 Что было сделано

В рамках этого этапа была реализована **система управления темой (светлая/тёмная)**.

### 🔧 Основные изменения:

- Добавлен компонент `ThemeSwitch`, который позволяет пользователю переключать тему одним кликом.
- Реализована логика хранения темы в `localStorage` — тема сохраняется между перезагрузками страницы.
- Создана система состояния темы с использованием `useReducer` и `Context API`.
- Исправлены ошибки TypeScript и webpack, связанные с типами и загрузкой файлов.
- Упрощён интерфейс: вместо двух кнопок — одна кнопка-переключатель.
